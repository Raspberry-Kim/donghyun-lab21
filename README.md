# 동현스 v0.42

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24435598.svg)](https://doi.org/10.5281/zenodo.24435598)

동현랭으로 출전 조건을 정하는 **1인용 세로 슈팅 게임**이다. 거친 미색 종이 위에 연필로 그린 비행기를 조종한다. 부제는 ‘연필로 그린 1945-2’.
동현 시리즈의 스물두 번째 작은 실험이다. 1997년 오락실 게임 「스트라이커즈 1945 II」의 큰 틀만 참고했고 엔진·그림·소리·글은 모두 새로 만들었다.

바로 하기: https://raspberry-kim.github.io/donghyun-lab21/

모든 판을 묶는 DOI는 [`10.5281/zenodo.24435598`](https://doi.org/10.5281/zenodo.24435598)이다. 이번 판은 [v0.42 릴리스](https://github.com/Raspberry-Kim/donghyun-lab21/releases/tag/v0.42)이다. 판마다의 Zenodo 보관본은 위 DOI 쪽의 판 목록에서 고른다.

## 규칙

- 오른쪽 동현랭 코드의 **출전**을 누르면 코드가 출력한 정수대로 생명 수·폭탄 수·시작 스테이지·배경 색이 정해진다. 이어서 게임 화면에서 **난이도**(초급·중급·상급, 중급을 권한다)와 **기체**를 고르면 시작한다.
- 스테이지는 일곱이다. 스테이지마다 가운데쯤 중간 보스, 끝에 보스가 나온다. 스테이지 7의 끝에는 끝판왕 흑심 대요새가 나온다. 일곱을 모두 클리어하면 팡파르와 꽃비로 축하하고 끝난다.
- 기체에서 탄에 맞는 곳은 한가운데의 작은 점이다. 날개 끝으로 스치는 탄은 지나간다. 날아다니는 적의 몸에 부딪혀도 기체를 잃는다. 땅 위의 적과는 부딪히지 않는다.
- **P**를 먹으면 샷이 한 단계 세진다(네 단계). **B**는 폭탄 하나(5개까지). 가득 찼을 때 먹으면 2,000점이다.
- 땅 위의 적을 부수면 **메달**이 나온다. 놓치지 않고 이어 먹으면 200 · 400 · 800 · 1,600 · 3,200점으로 오른다.
- 15만 점과 50만 점, 그 뒤로 50만 점마다 기체가 하나 는다. 스테이지를 클리어하면 남은 폭탄과 예비 기체만큼 보너스를 받는다.
- 기체를 모두 잃으면 게임 오버다. **이어 하기**를 고르면 그 자리에서 다시 날지만 점수는 0부터 다시 센다.

## 조작

- 키보드: ←→↑↓ 움직이기 · **X 또는 Space** 샷(누르고 있으면 계속 나간다) · **Z**를 누르고 있다가 떼면 모아 쏘기(0.5초 · 1.2초 · 2초에 한 단계씩, 세 단계) · C 또는 Shift 폭탄 · Enter·Esc·P 메뉴(계속 간다 · 소리 · 저장 · 불러오기 · 포기하고 출전 준비로) · M 효과음 · F 전체 화면.
- 손가락: 화면을 누른 채 끌면 끈 만큼 기체가 움직이고 샷은 저절로 나간다. 둘째 손가락을 화면에 대고 있다가 떼거나, 화면 아래 **모아 쏘기** 버튼을 누르고 있다가 떼면 모아 쏘기다. **폭탄**·**메뉴** 버튼도 화면 아래에 있다. 마우스로도 같은 방식으로 끌 수 있다.
- 게임패드(닌텐도 배치): A·R 샷 · B·L 모아 쏘기 · X·Y·ZL·ZR 폭탄 · 십자·왼 스틱 이동 · + 메뉴. A와 B가 거꾸로 들어오면 −(Select)로 바꾼다.
- 출전한 뒤 판 아래 **전체 화면** 버튼(또는 F)을 누르면 게임 화면이 비율을 지키며 화면을 꽉 채운다. 전체 화면에서 Esc를 누르면 브라우저가 전체 화면을 닫고, 게임은 메뉴를 열어 멈춘다.
- 게임 화면은 세로로 긴 240×320칸(3:4)이고 1초에 60걸음으로 움직인다.

## 저장과 불러오기

- 메뉴의 **저장**에서 **브라우저 칸 1·2·3** 가운데 하나에 남기거나 **파일로 내려받기**로 `.dhsave` 파일 하나로 내려받는다. 찬 칸은 덮어쓸지 한 번 더 묻는다. 저절로 저장되지는 않는다.
- **불러오기**에서 칸을 고르거나 **파일에서 불러오기**로 `.dhsave` 파일을 고르면 그 순간으로 돌아간다. 적과 탄의 자리, 난수의 상태까지 그대로다. 불러온 직후에는 멈춘 채로 기다린다.
- 출전 준비 화면에서는 동현랭 코드 아래 **저장한 판 불러오기**에 칸 세 개가 보인다. 칸은 이 기기의 이 브라우저에만 남는다.
- 최고 점수는 브라우저에 남기지 않는다. 쪽을 다시 열면 0부터다.

## 동현스 출전 규약

동현랭 코드가 출력한 **정수**를 차례로 읽는다. 첫 정수만 있어도 나선다.

| 자리 | 뜻 | 값 |
| --- | --- | --- |
| 첫째 | 생명 수 | `1`~`9`. 기체의 수다. 반드시 있어야 한다 |
| 둘째 | 폭탄 수 | `0`~`5`. 없으면 2. 새 기체가 나올 때 이 수까지 채워진다 |
| 셋째 | 시작 스테이지 | `1`~`7`. 없으면 1 |
| 넷째 | 배경 색 | `1` 미색(거친 미색 종이) · `2` 스케치북 흰색. 없으면 1 |

- 범위를 벗어나거나 정수가 다섯 이상이면 출전하지 않고 오류를 알려 준다.
- 난이도와 기체는 동현랭이 아니라 출전한 뒤 게임 화면에서 고른다.
- 예제 일곱: **01 기본 · 생명 3**(3), **02 넉넉하게**(5 4), **03 스케치북 흰색 종이**(3 2 1 2), **04 스테이지 3부터**(3 2 3), **05 마지막 스테이지 연습**(9 5 7), **06 기체 하나 · 폭탄 없음**(1 0), **07 흰 종이 · 스테이지 4 · 생명 2**(2 1 4 2).

```
나는 동현이냐?
ㅋㅋ 생명 3
뿡뿡 도오오옹~뿡뿡뿡
동현이구나
```

## 파일

- `index.html` — 묶은 한 파일(글꼴 포함). `node build.cjs`로 `src/`에서 만든다.
- `src/game.js` 엔진(기체·적·탄·보스·점수·저장) · `src/data.js` 기체·난이도·적·보스·스테이지 자료 · `src/sketch.js` 연필 선과 종이 · `src/art.js`·`art2.js`·`art3.js` 그림 · `src/terrain.js` 땅 · `src/render.js` 화면 · `src/input.js` 입력 · `src/app.js` 출전·메뉴·저장 · `src/examples.js` 예제 · `src/donghyun.js` 동현랭 실행기 v1.55 · `src/sfx.js` 효과음과 승리 팡파르 · `src/petals.js` 엔딩의 꽃비 · `src/gamepad.js` 게임패드 · `src/title.png` 시작 화면의 제목(제작자의 아내가 직접 쓴 글씨, 그림 파일은 이 한 장이다).
- `qa/save.cjs` 엔진 저장·불러오기 왕복 · `qa/weap.cjs` 기체 넷의 샷·모아 쏘기·폭탄 · `qa/docs.cjs` 문서 예시와 판 번호 · `qa/fuzz.cjs` 마구 누르는 입력으로 일곱 스테이지를 돌며 멈춤·저장 왕복을 봄(node). `qa/hitbox.cjs` 맞는 범위와 그림이 어긋나지 않는지 · `qa/ui.cjs` 쪽 전체 흐름 · `qa/touch.cjs` 손가락 입력 · `qa/full.cjs` 전체 화면 · `qa/run.cjs` 일곱 스테이지 자동 완주 · `qa/victory.cjs` 엔딩의 팡파르와 꽃비 · `qa/tabs.cjs` 탭·휴대폰·어두운 화면 · `qa/pad.cjs` 게임패드 버튼 배정(흉내 낸 패드) · `qa/glyph.cjs` 게임 화면에 쓴 글자가 모두 손글씨로 나오는지 · `qa/line.cjs` 줄여 그린 팬케이크의 선 굵기와 모양 · `qa/screens.cjs` 여러 화면 크기와 배율 · `qa/perf.cjs` 속도(Playwright). `qa/launch.cjs`는 이 시험들이 브라우저를 띄울 때 함께 쓴다.
- `tools/subset-font.py` — 게임 화면 손글씨(Gaegu)에서 쓰는 글자만 추린다. 게임 화면의 글을 고치면 다시 돌린다. 추린 글자는 `fonts/Gaegu.subset.txt`에 적힌다.

## 한계

- 배경 음악은 없다. 효과음과, 끝판왕을 이겼을 때의 짧은 승리 팡파르가 있다.
- 2인용, 스테이지 순서 섞기, 2주차는 없다.
- 난이도는 사람이 오래 해 보며 맞춘 것이 아니라 수로 정하고 자동 조종으로 완주를 확인한 것이다.
